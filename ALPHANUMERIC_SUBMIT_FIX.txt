Alphanumeric Miningcore submit fix
===================================

This build changes Alphanumeric live mining default submit format from object to miningcore.

Why:
- The RTX 5080 GPU was hashing correctly and finding shares.
- Miningcore rejected object-style submit with: error code 21, job not found.
- Miningcore Stratum handlers normally expect positional submit params:
  [user, job_id, extranonce2, ntime, nonce]

Use:
  --alpha-submit-format miningcore

Equivalent fallback:
  --alpha-submit-format bitcoin

If your custom pool module expects object submits, use:
  --alpha-submit-format object

Recommended command:
  .\Release\capminer.exe --algo alphanumeric --pool stratum+tcp://us.icminers.com:7182 --wallet YOUR_ALPHA_WALLET --worker rtx5080 --pass x --devices 0 --threads 256 --blocks-per-sm 32 --batch-ms 50 --alpha-submit-format miningcore --debug-shares --log-file alpha_debug.log --no-opencl
